## Pinion Diameter
Known:
$$L = 145mm, \theta = 150\degree - 5\degree = 145\degree$$
$$L=2\pi * R * \frac{\theta}{360}$$
$$L=\pi * D * \frac{\theta}{360}$$
$$D = \frac{L * 360}{\pi * \theta}$$
$$D = \frac{145[mm] * 360[deg]}{\pi [rad] * 145[deg]} = \frac{360[mm]}{\pi [rad]} = 114.59[mm] \therefore R = 57.30[mm]$$
## Tooth Count Pinion (And actual diameter)
Known:
$$desired\ module = 1.5[mm], D = 115[mm]$$
$$\#_{teeth} = \frac{Diameter[mm]}{Module[mm]} = \frac{115[mm]}{1.5[mm]} = 76\frac{2}{3} \approx 76\ teeth$$
$$Diameter_{Actual}[mm] = \#_{teeth} * Module[mm] = 76 * 1.5[mm] = 114[mm]$$
## Tooth Count Rack (And actual length)
Known:
$$Length = 145[mm], Module = 1.5[mm]$$
$$Length[mm] = \#_{teeth} * module[mm] * \pi[rad]$$
$$\#_{teeth} = \frac{Length[mm]}{module[mm] * \pi[rad]} = \frac{145[mm]}{1.5[mm] * \pi[rad]} = \frac{145[mm]}{4.71[mm]} = 30.79\ teeth \approx 31\ teeth$$
$$Length_{Actual}[mm] = \#_{teeth} * module[mm] * \pi[rad] = 31 * 1.5[mm] * \pi [rad] = 146.08405839193[mm] \approx 146.08[mm]$$
