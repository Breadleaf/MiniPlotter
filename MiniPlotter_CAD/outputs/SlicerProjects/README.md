# Slicer Projects

This dir is for template files to print each part. Some settings are optimized
for my Bambu Labs A1 and may need to be changed. One such example is the
```
Global -> Quality -> Precision -> X-Y hole compensation
Global -> Quality -> Precision -> X-Y contour compensation
```
settings. They have both been tuned with a few passes from my
[hole calibration project](https://github.com/Breadleaf/PrinterHoleCalibration)
